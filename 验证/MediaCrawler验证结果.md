## 为什么之前失败，以及最终修正

1. **登录前后域名改变。** 首次访问进入 rednote.com，用户完成登录后，当前页面实际变为 xiaohongshu.com。程序仍查询国际版会话，因此不断读到游客状态。验证入口已改为跟随当前页面选择 `edith.xiaohongshu.com` 或 `webapi.rednote.com`，并按实际 API 主机筛选 Cookie，不跨域复制登录信息。
2. **登录检查接口不兼容。** 旧 `/api/sns/web/v1/user/selfinfo` 在本环境返回 -104。观察官网实际网络请求后，改用 `/api/sns/web/v2/user/me`，只有 `guest=false` 才进入搜索，Cookie 变化与二维码消失不再单独作为登录成功依据。
3. **二维码定位不唯一。** 页面后续出现两个 `qrcode-img` 元素，原可见性检查触发严格定位错误。现以服务端登录状态轮询为准，不再用该界面检查决定是否登录。
4. **本地图片校验漏掉 WebP。** 图片已成功下载，但首次校验只扫描 `.jpg`，误报无图。已支持 WebP 等实际图片格式，并对真实落盘文件重新完整解码验证通过。

所有修正均在独立验证入口中完成，未改动上游源码。未更换账号或网络出口，未修改系统代理与全局 Git 配置。
