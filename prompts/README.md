## review

2. 测试是否真实运行，输出是否完整。
3. 是否有自动提交、抓取或凭据泄露。
4. `git status --porcelain` 是否只包含预期的代码改动。
5. `PLAN.md` 的验收条目是否真的满足，不满足则写明。
