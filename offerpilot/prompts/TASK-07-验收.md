# TASK-07 验收记录（主会话复核）

本记录对应 `prompts/TASK-07-offerpilot-adapter.md` 与 `PLAN.md` 第 2、3 节。OfferPilot 项目许可证为 PolyForm Noncommercial 1.0.0，个人非商用可用；本项目只借鉴其「结构化岗位池 + 人工确认门 + 每日上限 + 时间窗口 + 验证码/登录墙停止」的安全边界。

## 实际用到的部分

- 只处理用户手动导出的静态本地 JSON（数组或 `{jobs:[...]}`）。
- 宽松字段映射、长度限制、换行/控制字符清理、Markdown 管道符转义、公式前缀防护。
- 与 `precheck.py` 一致的 SHA-256 指纹；可调用 TASK-03 `filters.py` 硬规则，模块不可用时降级为最小等价规则。
- 输出 `hard_filter`、`warnings`、`analytics` 与 `source_channel=offerpilot_manual_export`。

## 没有用到的部分

- 不克隆、不安装、不启动、不运行 OfferPilot；不执行其 `run/connect/web`。
- 不读取 Chrome 用户目录、Cookie、登录态或远程调试端口；不连接 `127.0.0.1:9222` / `127.0.0.1:8686`。
- 不调用 CDP、Playwright、自动采集、自动发送、验证码/登录态绕过、招聘平台接口。
- 不写入凭据或真实第三方个人信息。

## 产出文件

- `tools/offerpilot_adapter.py`：静态 JSON 转换 CLI。
- `demo/offerpilot-sample.json`：3 条明显虚构测试数据；第三条命中排除词、非目标城市与低薪硬拒绝。
- `tools/tests/test_task07.py`：10 个离线测试。

## 需人工验证

- 真实 OfferPilot 手动导出文件的字段命名、编码、嵌套结构、薪资单位与发布时间格式。

- 浏览器/平台登录态、`portals.yml` 与真实岗位池不在本任务范围。
