# workspace · 本机个人工作区

这个目录存放**只在本机使用**的个人求职资料，整体被 `.gitignore` 忽略，只有本说明文件会提交到仓库。

| 文件 | 用途 |
| --- | --- |
| `resume.md` | 主简历（Markdown）。「个人资料 → 从简历导入」会读取它，只给出建议、不自动保存。 |
| `profile.yml` | 可选的结构化资料备份；当前工作台不直接读取，个人资料以 `web/data/<mode>/profile.json` 为准。 |
| `applications.md` | 投递记录（Markdown 表格），用于重复投递预检与状态跟踪。 |
| `portals.yml` | 可选的渠道配置，供后续扫描流程使用。 |

首次使用时手动创建这些文件即可；仓库不会提交其中的内容。不要把真实姓名、电话、邮箱、微信、简历原文或平台会话写进任何受版本控制的文件。
