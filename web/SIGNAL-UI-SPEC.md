# 「信号」界面打磨规格（ui-polish 分支）

状态：设计方案，实施中（2026-11-18）。实现完成并经主会话浏览器复核后，本节结论并入 `web/DESIGN.md`。

来源：用户自有原型「信号」（`复制即收藏/work/design-proposals/原型-20261112-信号/` 与 `设计规范-信号-20261112.md`）、`web/DESIGN.md` 的「信号」章节、frontend-design skill。只做桌面宽度（≥1100px）；手机宽度本轮不管，但不得新增横向溢出。

## 1. 这个界面是给谁、做什么

一个人在秋招季每天打开一次的本机工作台：看今天要处理什么 → 去流水线把岗位采集、筛选、通过、回复 → 偶尔补资料、改简历、练面试。主任务是「快速看清停在哪一步、下一步点哪里」。所以：

- 一处大胆：首页的超大窄体日期数字与深色概览卡（唯一的信号色余光）。其他页面安静、密度适中。
- 每页第一眼只回答一件事：这页的主操作是什么、为什么现在不能点（若禁用）。
- 说明文字退后：长段解释收进「这页怎么用」折叠，不占首屏。

## 2. Token（只引用，不在页面文件里另起颜色）

| 名 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` 画布 | #F2F3F0 | #0A0B09 | 页面底 |
| `--surface` 面 | #FFFFFF | #141512 | 面板、输入框 |
| `--ink` 墨 | #0D0E0C | #F1F2EC | 正文、主按钮底 |
| `--ink-2` 次 | #55574F | #A3A59C | 说明、表头 |
| `--mute` 元 | #8D8F87 | #6A6C64 | 时间、计数单位、占位 |
| `--line` 线 | 墨 8% | 墨 8% | 唯一分隔/描边 |
| `--sg` 信号 | #D2F53C | #D2F53C | 选中、计数徽标、聚焦、首页余光；浅色下小面积标记用 #9BC21A |
| `--sg-ink` | #0B0C08 | #0B0C08 | 信号色上的字 |
| 危险 | #FF5A4E | #FF5A4E | 只给删除 |

规则：信号色一屏不超过 5 处，不做大面积底，不做正文色。警告/错误沿用现有 `--warn/--warn-bg/--bad/--bad-bg`。

- 字体：正文系统无衬线（苹方）；页面标题与数字用窄体 `var(--sg-num)`，`font-variant-numeric: tabular-nums`。不加载远程字体。
- 字阶：页标题 40/700/-0.02em；面板标题 17/650；正文 14/1.6；说明 13/1.55 `--ink-2`；元信息 12 `--mute`；表头 12/600 `--ink-2`。
- 圆角：面板 22；面板内分组/卡片 14；输入 12；按钮、页签、徽标全圆胶囊。
- 阴影：只有浮层（弹窗、下拉、轻提示、底部操作条）用 `0 12px 32px -12px rgba(0,0,0,.18)`；其余一律 `inset 0 0 0 .5px var(--line)`。
- 动效：曲线 `--sg-spring`（到位）与 `--sg-soft`（颜色/透明度）；时长 160/320/560。切页 320ms 透明度 + 上移 8px（现为 560ms/12px，过慢，切页时整页发灰）；按压 0.965 回弹；首页任务行首次渲染错峰 32ms。只动 transform/opacity。`prefers-reduced-motion` 下全部关闭。

## 3. 通用组件规则（`sg-base.css` 负责）

1. 页头 `.view-head`：标题 + 一句话导语（≤ 40 字）。现有长导语保留原文，但折进页头下方的 `details.sg-help`「这页怎么用」，默认收起。
2. 流水线子页签 `.ui-hub-tabs`：一条胶囊轨道（`--accent-soft` 底），选中项墨底白字（深色下信号色）；序号与文字同一行，不换行。
3. 面板 `.panel`：22 圆角、`--surface`、内边距 20/22；`.panel-head` 左标题+一行说明，右侧计数用窄体数字。面板之间 16px。
4. 表格：`caption`「表：…」视觉隐藏（保留给读屏）；表头无灰底带，12/600 `--ink-2`，下边 1px 线，`position: sticky`；行最小高 48px；公司/岗位单行省略（完整内容在 `title`）；徽标、平台标、状态一律 `white-space: nowrap`；数字列右对齐、窄体；横向滚动只在 `.table-wrap` 内部，右侧加渐隐提示；悬停行 `--accent-soft`；选中行左侧 3px 信号色条。
5. 徽标 `.badge`：高 22、胶囊、不换行。good＝信号色底黑字；neutral＝线框；warn/bad＝对应浅底。平台标：14px 圆角方块里放平台首字 + 平台名。
6. 按钮：主操作墨底胶囊，悬停信号色；次操作 `--accent-soft`；删除只用危险色文字按钮。禁用：透明度 .4、`cursor: not-allowed`，并且旁边必须有一句可见原因（`.sg-disabled-reason`，13px `--ink-2`），没有原因的禁用按钮视为缺陷。
7. 空状态 `.sg-empty`：一句话说清缺什么 + 一个去下一步的按钮；不出现裸「暂无数据」。
8. 表单：标签在上（12.5 `--ink-2`），控件高 40；桌面两列网格；下拉选项文字 ≤ 20 字，解释放在字段下方帮助文字里。
9. 轻提示：顶部 `#status` 改为右上角浮起的胶囊轻提示，3 秒后淡出（错误类常驻直到下一次操作）；仍保留 `role="status"`。
10. 「未接入」占位面板（定制简历、信息推送里的 Agent 卡）与开发者信息（个人资料里的本机接口说明）移到页面底部，收成一行 `details`。
11. 顶栏：左侧显示当前页面名（不再重复「秋招规划师」），右侧「刷新数据」与生成时间。

## 4. 页面布局

### 首页（一处大胆）
```
┌───────────────────────────────┬────────────────────┐
│ 18   十一月 · 星期三            │ 岗位流水线          │
│ (140px 窄体)  今天还有 1 件待办  │ 采集   31          │
│ ┌ 深色概览卡 + 右上信号余光 ─┐   │ 筛选   12          │
│ │ 一句话：先做下面这些。      │   │ 通过    3          │
│ └──────────────────────────┘   │ 回复    0          │
│ 待处理岗位        0 个  [去确认] │ ───────────────    │
│ 待确认招呼语      1 条  [去发送] │ 最近动态（5 条）     │
│ 待回复 HR 消息    0 封  [去回复] │                    │
└───────────────────────────────┴────────────────────┘
```
左列 ≤ 640px，右列 320px；数字右对齐窄体。右列只用已有数据（`state.pipeline`、活动记录）。

### 岗位流水线
- 采集：左侧表单，右侧粘性「启动前检查」卡（检查项 ✓/✗ + 主按钮 + 禁用原因），主操作始终在首屏可见。
- 筛选/通过：表格按第 3 节；批量操作条在有选中时吸附在视口底部（`position: sticky; bottom: 16px`，浮层阴影），显示「已选 N 条」与可用操作。
- 回复：沿用现有三栏，统一徽标、空状态与发送框样式。

### 个人资料
左侧粘性分节导航（基本信息/求职偏好/教育/经历/项目/技能/简介/确认），每节显示必填是否完成（✓ 或「缺」）；右侧表单；顶部完整度条。

### 定制简历 / 模拟面试 / 信息推送
主功能面板在前；「未接入」卡沉底收起。模拟面试四张入口卡：窄体大计数 + 一句说明 + 进入按钮，等高。

### 设置
AI 接口在最前（状态徽标「已配置」用信号色），其次本地操作、下载文件；运行看板默认收起。

## 5. 文件分工（并行写入不重叠）

| 负责 | 样式文件（新建，只写自己的） | 允许改的标记与脚本 |
|---|---|---|
| 子会话 `1` | `web/static/sg-base.css`（Token 校准、第 3 节通用组件、顶栏、侧栏、首页、对话助理、设置） | `index.html` 的顶栏、侧栏、`#view-workbench`、`#view-agent`、`#view-data`；`app.js` 的 `renderAll` 中首页渲染、`showView` 里顶栏标题、`#status` 轻提示逻辑、`renderData/renderConfig` |
| 子会话 `ui-main` | `web/static/sg-pipeline.css`（`#view-collect/#view-jobs/#view-queue/#view-mail`） | `index.html` 的 `#view-collect`、`#view-queue`、`#view-mail`；`app.js` 的 `renderOfferPilot*`/`renderCollect*`、`renderQueue*`、`renderDeliveryResults`、HR 渲染函数。`#view-jobs` 只写 CSS（`offerpilot-city` 正在 main 上改它的标记和脚本） |
| 子会话 `variants` | `web/static/sg-tools.css`（`#view-profile/#view-resume/#view-interview/#view-push`） | 这四个 `#view-*` 区段与对应渲染函数 |

- 选择器统一以 `body.offer-ui:not(#wa-theme-off)` 开头（与现有「信号」层同优先级），页面文件再加 `#view-xxx`。
- 不改 `offer-theme.css`、`workbench-agent.css`、`ui-signals.css`、`styles.css`；需要覆盖就在自己的新文件里写。
- 只加不删 id / `data-*`；新 id、class 带 `sg-` 前缀。
- 加载顺序：`sg-base.css` → `sg-pipeline.css` → `sg-tools.css`（已在 `index.html` 与 `server.py` 接好）。
