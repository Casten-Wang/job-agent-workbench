## 一、设计目标与风格判断

### 产品类型与体验目标

本机求职工作台里的文字面试。进入后先在四张流程卡片里选模块。打开模拟面试后，求职者要看清当前这一问、自己刚发送的回答，以及这场还剩多少时间。对话是该模块的主任务。准备度复盘在「面试复盘」模块，不堆在对话下面。

体验判断：当前问题占据阅读焦点；回答输入始终留在对话区底部。进度用剩余分钟说明，例如「剩余 18 分钟」，不展示接口状态名，也不显示「第 n / 10 问」。

### 视觉风格

沿用现行工作台：浅青灰画布、深青文字、细线分隔、无阴影、面板不另加圆角。面试官和求职者靠对齐和底色区分，不靠头像或装饰气泡。

### 关键 UX 规则

- 主按钮随状态只有一个：未开始时是「开始这场面试」；进行中是「发送回答」；本轮计划完成或时长用完后，主按钮改为「结束面试」。在此之前不渲染结束。
- 面试官文字逐字追加到当前问，不先出整段再替换。`prefers-reduced-motion` 时仍逐字出现，只去掉非必要过渡。
- 空白回答不发送。失败时保留已提交回答和已出现的半句，并在该问下写明这一问没有说完。
- 长问题和长回答在对话记录内滚动。输入框固定在对话区底部。
- 复盘展示准备度、带证据的 1–5 分、一个优先修正项和简历修改点。旁边写「这些修改点不会自动写入定制简历」。分数不表示录用。

### 层次、阴影与动效

不新增阴影。面试官回合用浅底和左对齐，求职者回合用白底、右对齐。逐字出现不加光标闪烁。用户开启减少动效时，不使用滑动或淡入。

## 四、界面清单与页面设计

### UI-001 模拟面试对话区

- **依据与目标**：REQ-001、REQ-002。在现有 `#view-interview` 按所选轮次和时长完成一场文字面试，并查看带证据分数的复盘。无单独原型文件。
- **布局结构**：阅读顺序为四张卡片入口，进入模拟面试后是本场轮次时长岗位和 JD、当前进度、对话记录、回答输入。知识库、Mock 题单和复盘不在这个模块里。结束前主操作在输入区右侧。结束后到「面试复盘」查看准备度，输入区改为不可再发送。
- **内容呈现**：一问一答各占一行块。问题超过容器宽度时换行，不截断。简历修改点在面试复盘里用有序列表，每条完整显示。其他公司同类岗位面经在使用时标明不是该公司面经。来自联网的条目标明「来自联网」。
- **组件清单**：

| 区域 | 组件 | 内容 | 交互 | 风格 |
| --- | --- | --- | --- | --- |
| 入口 | 四张 pipeline-node | 模拟面试、Mock 题单、面试复盘、题库与面经 | 点卡片进入模块，可返回 | 与工作台核心流程卡片相同 |
| 本场 | 轮次、时长、岗位、JD | 本场条件 | 无面经勾选，无本场上传，无知识库表单 | 现行表单 |
| 进度 | 文字 | 剩余分钟；必要时一句联网说明 | 只读 | 说明色 |
| 记录 | 回合块 | 面试官问题、求职者回答 | 记录内滚动 | 面试官浅底，求职者右对齐 |
| 输入 | 多行文本加主按钮 | 回答或结束 | 未到结束条件只显示发送；计划完成或时长用完后显示结束 | 主按钮 |
| 复盘 | 卡片 | 准备度、带证据的分数、点评、优先修正项、简历修改点、重练 | 重练一次只改一个缺口 | 面板色 |

- **状态与操作结果**：
  - 简历没有实习或项目 → 点开始 → 提示先写实习或项目，不出现问题。没有岗位和 JD 时可以开始，并标明「本轮是通用岗位模拟」。
  - 知识库没有本场相关内容且搜索未配置或失败 → 点开始后说明「这次没有联网补充」，面试仍继续。
  - 依据足够且简历有实习或项目 → 点开始 → 主按钮变为「正在根据简历准备问题」并禁用，页面不出现考查点；第一问逐字出现后，按钮恢复为「发送回答」。
  - 输入为空 → 发送保持禁用。
  - 发送有效回答且尚未结束 → 回答进入记录，按钮再次变为「正在提问」，下一问逐字出现。
  - 计划完成或时长用完 → 输入禁用，主按钮改为「结束面试」。
  - 点结束 → 按钮为「正在生成复盘」；完成后显示准备度、带证据的分数、优先修正项、简历修改点，并写明不会自动写入定制简历，也不表示录用。
  - 半句中断 → 该问保留半句和「这一问没有说完」，主按钮变为「重试这一问」。已发送的回答仍在记录里。
  - 点重新开始 → 当前记录清空，已完成的复盘卡片仍留在下方历史中。
- **示例数据与文案**：演示用虚构内容。面试官：「请讲一次你在实习里把需求范围缩小的经历。」求职者：「我把首期范围收成注册和支付，两周后上线。」进度显示「剩余 18 分钟」。复盘写「证据不足」，不给无证据的高分。修改点：「简历里的该项目补上首期范围和两周上线，不写未提到的指标。」
- **页面例外**：对话记录使用内部滚动，页面其余部分仍走现有页面滚动。
